# «Генерал Ксанакса» — сборка Windows

## Важно
Архив исходного проекта не содержал `requirements.txt`, модели Qwen3-TTS и пользовательских голосов. Поэтому здесь добавлена конфигурация сборки, но готовый Windows Setup нельзя корректно собрать на Linux: PyInstaller должен собирать Windows-приложение на Windows.

## Требования
- Windows 10/11 x64
- Python 3.12 x64
- NVIDIA GPU и совместимый драйвер для CUDA 12.6
- Inno Setup 6 (для создания установщика `Setup.exe`)
- Модель `Qwen3-TTS-12Hz-0.6B-Base` отдельно

## Сборка
1. Распакуйте весь проект в папку, например `C:\\VoiceForgeRU`.
2. Установите Python 3.12 x64 и Inno Setup 6.
3. Откройте PowerShell в папке проекта.
4. Выполните:

   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   .\\build_windows.ps1
   ```

5. После успешной сборки установщик будет здесь:
   `installer\\Output\\GeneralXanaxa-Setup.exe`

## Данные пользователя
Голосовые профили, история и созданные WAV хранятся в `%LOCALAPPDATA%\\GeneralXanaxa`, а не в папке установки. Удаление программы их не стирает.

## Модель
Модель не включается в Setup. После первого запуска откройте «Настройки» → «Выбрать папку модели Qwen3-TTS» и укажите папку, внутри которой находится `config.json`.

Если у вас осталась старая модель в `C:\\VoiceForgeRU\\models\\Qwen3-TTS-12Hz-0.6B-Base`, приложение попробует использовать её автоматически.
